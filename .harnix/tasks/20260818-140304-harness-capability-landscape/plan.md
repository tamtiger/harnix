# Kế hoạch nghiên cứu capability harness

## Checklist

- [x] Khóa baseline Harnix và failure modes chưa được xử lý đầy đủ.
- [x] Thu thập landscape và nguồn sơ cấp cho 10–20 ứng viên.
- [x] Xây capability matrix, scoring và gap analysis.
- [x] Chọn recommendation, deferred/rejected scope và roadmap tối đa năm item.
- [x] Kiểm tra traceability, consistency và boundary compliance.

## Trình tự

1. Đọc nguồn sự thật nội bộ và lập baseline capability hiện có.
2. Duyệt official docs/repository/release notes/test của ứng viên; không chạy code tải về.
3. Tách fact, inference và recommendation; dừng khi nguồn mới khó thay đổi quyết định.
4. So sánh từng capability với ranh giới và chi phí Harnix.
5. Persist báo cáo task-owned và thực hiện ba check read-only trong validation plan.
